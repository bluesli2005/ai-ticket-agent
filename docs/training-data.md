# 分类训练数据说明

本次由 64 条扩充至 192 条：训练 144 条、测试 48 条，四类均衡，每类训练 36 条、测试 12 条。保留原有全部样本和 train/test 划分；新增文本无完全重复。全部为人工编写的合成中文工单，不含真实客户数据。

类别为账号登录、支付账单、系统故障、功能需求。既有能力无法正常使用归系统故障；尚未提供的能力建议归功能需求。身份、账号生命周期及访问授权归账号登录；收费、退款、发票归支付账单。多意图或模糊描述需要人工确认。

对同一扩充测试集，旧模型 accuracy=0.5000，新模型 accuracy=0.8750、macro F1=0.9129；原有 16 条测试仍全部通过。拒识计入准确率错误，详细失败样本见 training-comparison.json。未根据测试错误再次调整样本。

该测试与训练集由同一次合成工作编写，存在主题和措辞相关性，不是独立生产评估；未做语义去重或跨来源留出。真实业务效果需后续用人工标注、脱敏且独立留出的真实工单验证。模型分数未经概率校准。

本次训练仅更新朴素贝叶斯分类器，不微调 Ollama 大模型，也不增加 RAG 文档。已有工单历史分析不会被批量改写；重新分析才采用当前分类器。
