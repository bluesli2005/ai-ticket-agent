# AI 工单分类器：第一个能运行的机器学习项目

纯 Python 标准库 + HTML/CSS/JavaScript。无需 pip install、API Key、GPU 或大模型下载。
这是从数据训练的传统机器学习 demo，不是大语言模型、RAG 或聊天机器人。

## 启动

要求 Python 3.10+。进入项目目录后执行：

```bash
python3 app.py
```

浏览器打开 http://127.0.0.1:8765 ，输入中文工单并点击“识别类别”。终端按 Ctrl+C 停止。
端口占用时使用 `python3 app.py --port 8766`，浏览器也改为对应端口。
服务只监听本机；文本不上传云端，预测内容不持久化。服务器仅供本地学习，不用于公网部署。

## 你能学习什么

1. `dataset.json`：48 条训练样本、16 条测试样本，全部为本项目人工编写的中文教学数据。四类为账号登录、支付账单、系统故障、功能需求。
2. `model.py`：字符二元组提取、类别统计、Laplace 平滑、对数概率、分数归一化。参数从训练样本计算，没有写死关键词到类别的映射。
3. `app.py`：启动时训练；提供预测 API、重新训练 API、评估 API；验证输入并处理错误。
4. `index.html`：表单提交、fetch、加载状态、预测结果和错误展示。
5. `test_model.py`：检查换标签后模型会改变预测、未知内容拒识、概率归一化、拒识计入评估错误。

模型使用多项式朴素贝叶斯。算法参考：[scikit-learn 官方说明](https://scikit-learn.org/1.1/modules/naive_bayes.html)。本实现为教学手写版本，不依赖 scikit-learn。

## 做三个小实验

### 1. 完成一次预测

输入“我的订单被重复扣款了，请退款”，观察分类与支持第一候选的特征片段。

### 2. 改数据、重新训练

在 `dataset.json` 的数组中加入一个训练样本，例如：

```json
{"text": "希望增加深色主题", "label": "功能需求", "split": "train"}
```

点击网页“重新训练并评估”，再输入近似但不相同的句子，观察分数变化。样本需要合法 JSON。
初期保留现有四个类别，先各增加 10–20 条不同表达。重新训练从磁盘读取数据，浏览器没有编辑训练数据的功能。

### 3. 找到模型失败的地方

尝试“没有扣款问题，我只是无法登录”或同时涉及退款和登录的工单。字符模型不理解复杂否定、多重意图或完整语义。
把新案例保存为未来测试集，不要把测试样本直接复制到训练集。若反复根据现有测试集调参，需要另外保留最终未见测试集。

## 验证与 API

```bash
python3 -m unittest -v
python3 app.py --evaluate
curl -s http://127.0.0.1:8765/api/report
curl -s http://127.0.0.1:8765/api/predict -H 'Content-Type: application/json' -d '{"text":"页面白屏打不开"}'
```

`GET /api/report` 返回准确率、Macro F1、各类别 Precision/Recall/F1、混淆矩阵和全部测试案例。
`POST /api/train` 接收 `{}`，重新读取样本并替换内存模型。
`POST /api/predict` 接收 `{"text":"..."}`，返回类别、相对得分、特征覆盖率和特征贡献。
`evaluation.json` 是初次交付时的评估快照，修改数据后以 API 或命令输出为准。

## 限制

- 样本少，训练与测试都由同一作者编写，表达相近；测试分数不能代表真实业务表现。
- 显示的得分未经校准，不等于正确率，朴素贝叶斯可能过度自信。
- 覆盖率低于 15% 或最高得分低于 65% 时标为“需要人工判断”；这是教学启发式，不能可靠识别所有无关内容。
- 仅为中文单标签分类；没有多语言训练、深层语义理解、知识库检索或生成回答能力。
- 内存模型每次启动自动重新训练，不生成二进制模型文件。
